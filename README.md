# dsdsurin-ebook

E-book ข่าวเด่นประจำเดือน สำนักงานพัฒนาฝีมือแรงงานสุรินทร์ (กรมพัฒนาฝีมือแรงงาน กระทรวงแรงงาน)

เว็บไซต์: https://ebook.surinskill.net/

โครงสร้าง: โฟลเดอร์ละเดือน (ปี พ.ศ.-เดือน เช่น `2569-11/`) สร้างและเผยแพร่โดยระบบ DSD SURIN NEWS CENTER
ด้วยสคริปต์ `publish-ebook.ps1` ห้ามแก้ไฟล์ในโฟลเดอร์เดือนด้วยมือ ห้ามใส่รหัสผ่านหรือไฟล์ส่วนตัวใน repo นี้ (repo เป็นแบบสาธารณะ)

เผยแพร่ผ่าน Cloudflare Workers Static Assets (ตั้งค่าใน `wrangler.jsonc`)
